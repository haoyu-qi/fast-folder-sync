共享记忆

换电脑、换 Agent，也能接着理解你。

让同一个项目在不同电脑上对应起来

先创建共享项目；其他电脑同步后，选择已有项目并关联本机目录。

关联本机项目

提供给哪些 Agent

关联后点击“提供记忆”，为所选 Agent 安装可撤销的读取入口。

只带走你选择的内容

识别已有记忆和规则，预览后勾选。每个来源都需要指定所属项目；个人规则可选“个人通用”。不会采集聊天记录、Skills 或登录配置。

连接另一台电脑

各电脑使用同一个专用文件库或共享目录，再关联各自的本机项目。记忆正文会同步到所选位置；凭据和本机项目路径配置留在本机。

选择空目录，或另一台电脑已经使用的 Agent Sync 共享目录。

保留原文，整理成更好用的记忆

将经验整理为主题摘要，规则保持原意。摘要始终从原文生成；模型不可用时继续无损同步。

配置后，选择的经验记忆原文会发送到此模型服务，可能产生费用。密钥通过操作系统加密，只保存在本机。
