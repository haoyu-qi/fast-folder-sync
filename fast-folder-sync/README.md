# Fast Folder Sync 桌面客户端

当前产品版本 **0.2.2**。独立运行的文件夹备份与同步软件，无需安装 Obsidian。配套版本下载与服务端部署见[仓库 README](../README.md)。

## 产品说明

支持文档、照片、视频、代码和其他二进制文件。可在本地目录、移动磁盘和已挂载网络目录之间单向备份或双向同步，也可通过 Folder Sync 私有服务在多台电脑间双向同步。

提供多任务、定期自动同步、排除规则、托盘后台运行、冲突副本和历史恢复。删除传播默认关闭；覆盖和删除前保存本地历史版本。配套服务使用完整 SHA-256 校验与通用二进制传输。

Windows 使用蓝紫渐变、半透明侧栏、任务概览卡片与磨砂弹窗，接入系统窗口按钮和原生亚克力材质。

![Windows 客户端](../docs/images/desktop.png)

Mac 使用专属毛玻璃布局，支持系统浅深主题、菜单栏后台运行、任务搜索和状态筛选，以及 ⌘N / ⌘F / ⌘1～3 快捷键。

![Mac 布局预览（Windows 环境）](../docs/images/desktop-mac.png)

## 安装与使用

从 [0.2.2 发布页](https://github.com/haoyu-qi/fast-folder-sync/releases/tag/v0.2.2)下载客户端：Windows x64 便携 EXE 可直接运行；Mac 根据芯片选择 arm64 或 x64 的 DMG / ZIP，将应用拖入「应用程序」。Mac 需要 macOS 13+。

Windows 包未签名；Mac 包为本地 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。详细安装与构建方式见 [Mac 说明](docs/desktop-mac.md)。

1. 点击「新建任务」，选择源文件夹。
2. 本地备份选择目标目录和模式；跨设备同步选择「Folder Sync 私有服务」，填写服务根地址、文件库名与设备令牌。
3. 设置核对间隔和排除规则，保存后自动核对，也可点击「立即同步」。
4. 在「同步记录」查看结果；恢复前关闭该任务自动同步，再到「历史版本」选择需要的版本。

关闭窗口后继续后台运行，完全退出使用托盘或菜单栏中的「退出」。每个任务使用独立目录，源与目标不能相同或嵌套。

完整操作与源码构建见[桌面使用说明](docs/desktop.md)，验证记录见[0.2.2 验证](../docs/VALIDATION-0.2.2.md)。保留的原插件源码在 `src/`，上游说明见[原插件文档](docs/README.upstream.md)与[来源](UPSTREAM.md)。
