# Fast Folder Sync 0.2.2

网页服务端与桌面客户端统一为蓝紫毛玻璃风格。本版本配套提供 Windows 客户端、Mac 两种架构客户端，以及 Windows / Linux 服务端。

## 更新内容

- 网页管理台统一字体、配色、半透明侧栏、四项概览卡片、文件库卡片、文件表格与磨砂弹窗；登录、备份、设备、回收站、存储和设置页同步更新。
- 适配手机导航遮罩、关闭与键盘焦点，补充当前页面的辅助技术状态，以及减少动态效果、减少透明度和高对比度样式。
- 无有效执行时间时显示「尚未运行」或「待安排」，避免显示无效日期。
- README 改为产品说明和部署说明，补齐客户端安装、Docker / 原生部署、设备连接、备份与升级，并更新实际界面截图。
- 产品版本统一为 0.2.2；服务内核保留上游 3.6.1。同步协议与现有数据目录兼容。

## 下载

Windows 客户端为便携 EXE。Mac 的 M 系列芯片选择 arm64，Intel 选择 x64，使用 DMG 或 ZIP，需要 macOS 13+。Windows / Linux 服务端 ZIP 已内嵌新管理台，解压后运行启动脚本，再打开 `http://127.0.0.1:9000/webgui/`。

Windows 包未进行代码签名。Mac 包在 macOS runner 构建并使用本地 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证；CI 运行不代替所有 Mac 机型的人工验收。

同版 `SHA256SUMS.txt` 用于核对下载完整性。使用说明见[产品与部署说明](https://github.com/haoyu-qi/fast-folder-sync/blob/v0.2.2/README.md)。

## 升级

升级前停止服务并备份配置、数据库和文件存储。替换原生程序时保留 `config/` 与 `storage/`；Docker 从新标签重新构建，保留原命名卷。桌面端保留应用数据目录中的任务与历史版本。

检查与实际验证记录随源码保存在 `docs/VALIDATION-0.2.2.md`。
