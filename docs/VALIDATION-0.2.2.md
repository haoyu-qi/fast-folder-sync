## 发布与边界

产品标签触发[配套发布工作流](../.github/workflows/release.yml)。工作流在 Windows / Linux 原生构建并启动验证服务端，在 Windows 验证便携包，在 macOS runner 验证 Mac 界面及文件恢复，构建 arm64 / x64 的 DMG / ZIP。各项检查完成后才发布完整附件与 SHA-256 清单，执行结果见 [Actions](https://github.com/haoyu-qi/fast-folder-sync/actions/workflows/release.yml)。

Windows 包未签名；Mac 包为本地 ad-hoc 签名，无 Developer ID 签名或 Apple 公证。CI 运行不代替所有机型的人工验收。Docker、第三方云存储及外部 OIDC 未在本地环境实际验证。
