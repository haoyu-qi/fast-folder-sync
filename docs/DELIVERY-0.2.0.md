# Folder Sync 0.2.0

已将桌面端和服务端适配为通用文件夹备份、双向同步软件。管理台使用暖白背景、灰褐侧栏、陶土色按钮和衬线标题，移除了笔记编辑、知识库和 Obsidian 授权入口。

## 交付物

- `Fast-Folder-Sync-0.2.0-Windows-x64.exe`：独立桌面便携版。
- `Folder-Sync-Server-0.2.0.zip`：包含 Windows amd64、Linux amd64 服务端及启动脚本。
- `Folder-Sync-0.2.0-source.zip`：两端完整源码和开发说明，含 Docker 构建配方。
- `Folder-Sync-server-preview.png`、`Folder-Sync-desktop-preview.png`、`Folder-Sync-mobile-preview.png`：实际运行截图。
- `Folder-Sync-0.2.0-SHA256SUMS.txt`：交付包校验摘要。

## 启动并连接

1. 解压服务端包，Windows 打开 `windows-amd64/start.cmd`。
2. 访问 `http://127.0.0.1:9000/webgui/`，创建首个账户。
3. 新建文件库，在「连接设备」中生成设备配置。
4. 打开桌面 EXE，新建任务，选择本地文件夹和「Folder Sync 私有服务」。填写服务根地址、相同文件库名及设备令牌，保存后同步。
5. 多台电脑连接同一个文件库即可同步。跨设备连接时将地址换成服务端可访问的主机地址。

也可以在桌面端直接选择两个本地目录，进行单向备份或双向同步，无需服务端。程序关闭窗口后继续在托盘运行；完全退出使用托盘菜单。

服务端备份需要先配置「存储位置」，再创建「备份任务」。文件删除可进入回收站恢复；桌面覆盖和删除前会保存本地历史版本，删除传播默认关闭。

## 验证与范围

桌面端 20 项测试、管理台 4 项测试、Go 的 6 个核心包测试通过。真实本机服务完成 9 项跨端检查，覆盖两台客户端、二进制与空文件、26 MiB 大文件修改、下载字节一致性、删除恢复、权限拒绝和归档。最终 Windows 桌面包验证了界面创建任务、备份、覆盖归档和历史恢复。

配套客户端与服务端使用完整 SHA-256，所有新文件统一二进制传输；原有文本资源和同步接口继续兼容。服务端内部保留原模块及数据库名称，便于迁移，核心版本号仍沿用上游 3.6.1，改造交付版本为 0.2.0。

Linux 为交叉编译；Docker、第三方云存储和外部 OIDC 未在当前环境实测。Windows EXE 未签名。本次没有修改用户的现有部署，也没有推送远端仓库。迁移已有服务前请先备份数据库、配置与文件目录。

源码入口：`fast-folder-sync/docs/desktop.md` 与 `fast-folder-sync-service/README.folder.md`。新控制台保留核心文件、设备、备份、存储和账户操作；旧管理员用户编辑器、Git 设置与高级 Stytch 页面未重建，底层 API 保留。
