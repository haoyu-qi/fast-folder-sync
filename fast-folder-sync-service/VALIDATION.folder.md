# 0.2.0 验证记录

时间：2026-10-27，Asia/Shanghai。

## 实际通过

- 管理台前端：4 项自动测试通过；语法检查、生产构建通过。
- Go：API 路由、WebSocket 路由、认证中间件、业务服务、文件摘要工具、本地存储 6 个包的测试通过。
- 修复并回归验证 Windows 本地存储创建新目录、平级文件和二进制内容的问题。
- 桌面客户端：20 项测试通过；增加能力识别、能力缓存、统一二进制传输与完整 SHA-256。最终 Windows 便携版真实窗口验证了备份、覆盖归档和历史恢复。
- 本地启动真实 Go 服务，完成 9 项跨端联调检查：创建文件库、流式上传、旧文本统一展示、HTTP 字节一致下载、两台客户端同步、大文件未采样区域修改后的完整同步、删除与恢复、未认证访问及伪造管理台请求拒绝、本地归档生成。
- 备份归档实际生成，包含 9 个文件、原始数据总量 27,263,141 字节；归档为测试目录中的 ZIP 文件。
- 浏览器实际操作：登录、新建文件库、搜索文件、下载 JSON 文件、编辑保存备份计划、查看备份历史；页面中移除了在线笔记编辑和 Obsidian 授权入口。

联调脚本：`scripts/folder-sync-e2e.cjs`。此脚本只接受本机地址，创建独立测试账户和数据；不会连接生产服务。重跑可通过 `FFS_E2E_USER_FILE` 复用首次生成的测试账户，因为首个账户建立后服务会关闭公开注册。

## 来源与边界

上游仓库 `haierkeys/fast-note-sync-service` 固定提交：`7a6c78792c631f999c8a5f725bba5dd7235d6688`。使用官方 CNB 镜像取得完整源码，已确认提交与 GitHub 一致。

Windows amd64 原生服务和客户端已运行验证。Linux amd64 为交叉编译；Docker 配方、真实第三方云存储、远程反向代理、OIDC 身份提供商和高级 Stytch 授权未在当前环境实测。

没有向用户的实际云端服务部署，也没有推送 GitHub / CNB。服务端内部仍使用兼容的原始模块、数据库表和部分 API 名称，新控制台使用通用文件管理文案。
